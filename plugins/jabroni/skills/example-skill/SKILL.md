# Example Skill

This is a placeholder. Delete this folder once you add real skills.

To add a new skill:
1. Create `plugins/jabroni/skills/<skill-name>/SKILL.md` with `name` and `description` frontmatter.
2. Add any supporting files (`references/`, `scripts/`) alongside it.
3. Reload plugins in Claude Code (`/plugin marketplace update jabroni-skills` if already installed, or reinstall).
